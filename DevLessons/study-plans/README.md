# Study Plans

This folder contains one detailed study plan per DevLessons PDF.

Daily cadence for every plan:
- Study 2 to 3 hours per day
- Study 6 days per week
- Use the 7th day for retrospective, review, and catch-up

How to use the plans:
- Start each week by previewing the chapter or section titles.
- Spend the first pass understanding structure, then do a second pass for details.
- Turn each session into notes, questions, and one concrete output.
- Use the retrospective day to measure recall, not just reading completion.

Each PDF plan is organized by week and by day so you can follow it like a training cycle.
